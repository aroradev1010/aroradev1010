## <picture><img src="https://github.com/7oSkaaa/7oSkaaa/blob/main/Images/IDEs.gif?raw=true" width="50px"></picture> Selected Work

**[API Monitoring Platform](https://github.com/aroradev1010/Api-Debugger)** `Node.js` `Express` `TypeScript` `MongoDB`

- SDK for monitoring backend services by collecting requests, responses, errors, performance metrics, and service activity.
- Events are processed by a **Machine Learning pipeline** to classify errors, identify patterns, and estimate root causes, with a **rule-based fallback** when ML is unavailable.
- **SSE-powered** dashboard with request inspection, service health, filtering, alerts, historical analytics, authentication, and REST APIs.
- Organized into separate **SDK**, **backend**, and **frontend** packages, with automated testing using **Jest** and **Supertest**, **Docker** for local development, and **GitHub Actions** for CI.

**[AI-Powered Blogging Platform](https://github.com/aroradev1010/Infinite_Ideas_Hub_Next_JS)** `Next.js` `TypeScript` `Node.js` `MongoDB`

- Publishing platform with **AI-assisted writing**, **secure authentication**, **role-based access control**, image uploads, and **draft/publish workflows**.
- Custom **Lexical editor** supporting reusable plugins, **HTML/Markdown serialization**, **server-side content sanitization**, autosave, and rich-text editing.
- Authenticated **REST APIs** for user and content management, built with **Next.js SSR**, reusable components, and a modular architecture.
